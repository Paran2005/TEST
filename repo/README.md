# YANG-MAI–DAI-KID OS 2.0 · Org-Twin demo

ต้นแบบเว็บแบบ static สำหรับนำเสนอแนวคิด ใช้ข้อมูลสังเคราะห์และทำงานในเบราว์เซอร์

## นำขึ้นเว็บเพื่อแชร์

### GitHub Pages
1. สร้าง repository ใหม่บน GitHub แล้วอัปโหลด `index.html` จากโฟลเดอร์นี้
2. ไปที่ **Settings → Pages**
3. เลือก **Deploy from a branch**, เลือก branch `main` และโฟลเดอร์ `/ (root)` แล้วกด Save
4. รอ GitHub สร้างหน้าเว็บ จากนั้นแชร์ URL ที่แสดงในหน้า Pages

### Netlify หรือ Vercel
ลากโฟลเดอร์นี้เข้าเครื่องมือนำเข้าเว็บแบบ static หรือเชื่อม repository แล้ว deploy ได้เลย ไม่ต้องตั้งค่า build command

## หมายเหตุ
- หน้าเว็บนี้ไม่มี backend; ข้อมูลที่บันทึกในต้นแบบอยู่ใน Local Storage ของเบราว์เซอร์แต่ละคน
- ข้อมูลกำลังคนและผลจำลองเป็นข้อมูลสมมติ ไม่ใช่ข้อมูลหน่วยงานจริง
- หากเผยแพร่สาธารณะ ให้ตรวจข้อความ/ข้อมูลที่เติมภายหลังว่าไม่มีข้อมูลส่วนบุคคลหรือข้อมูลภายใน

## ตัวอย่างสถานการณ์ใน OS

มีสถานการณ์จำลองตั้งต้น 50 เรื่องที่เชื่อมกับองค์การภาครัฐไทย แสดงหมวดประเด็นและจำนวนก่อน แล้วจึงกดหมวดเพื่อเปิดดูสถานการณ์ในหมวดนั้น ช่วยลดการเลื่อนผ่านรายการที่ไม่สนใจ แต่ละเรื่องระบุหน่วยงานเจ้าภาพ หน่วยงานคู่ประสาน ภารกิจ และสมมติฐานสำหรับจำลอง ค้นหาตามชื่อภารกิจ หน่วยงาน หรือผู้เกี่ยวข้องได้


## เพิ่มเติมในรุ่นนี้
- เลือกภารกิจจากแผนที่สรุปภูมิภาคและจังหวัดตัวอย่าง 24 จังหวัด
- สร้างสถานการณ์และแผนทางเลือกของทีมเองได้ โดยบันทึกใน Local Storage ของเบราว์เซอร์
- เลือกหน่วยงานต้นทาง/ปลายทางและดูรหัสบุคลากรสมมติรูปแบบอักษร + เลข 4 หลัก + อักษร
- ทุกหน้าแสดงขั้นตอนการใช้งาน และการจับคู่คนเป็นเพียงข้อมูลจำลอง ไม่ได้สั่งโอนย้ายจริง
- ช่องกำหนดสถานการณ์รองรับสมมติฐาน 0–100% ในทุกตัวแปร (งานเพิ่ม กำลังคนไม่พร้อม กำลังบริการดิจิทัล และความล่าช้าประสานงาน) เพื่อทดลองกรณีขอบเขตสูงสุดได้
- สถานการณ์ทั้ง 50 เรื่องเป็นตัวอย่างสมมติสำหรับการออกแบบบริการและการประสานงาน ไม่ใช่เหตุการณ์จริงหรือข้อเสนอคำสั่งทางราชการ
- เอกสารต้นทางไม่พบในโฟลเดอร์ `sources` ของสำเนาโปรเจกต์นี้ จึงใช้ขอบเขตและแนวคิด YANG-MAI–DAI-KID ที่ผู้ใช้ส่งไว้ก่อนหน้า แล้วเติมกรณีภาครัฐไทยเพื่อการนำเสนอ
