# YANG-MAI–DAI-KID OS 2.0 · Org-Twin demo

ต้นแบบ static เพื่ออธิบายการจำลองการจัดกำลังคนและประสานงานภาครัฐไทย

## สถานการณ์
- มีตัวอย่าง 50 สถานการณ์ ครอบคลุมบริการประชาชน ภัยพิบัติและสิ่งแวดล้อม สุขภาพและสังคม เศรษฐกิจและพื้นที่ กำลังคนและโครงสร้าง และข้อมูลและธรรมาภิบาล
- แต่ละสถานการณ์ระบุหน่วยงานเจ้าภาพ คู่ประสาน ภารกิจ และสมมติฐานสำหรับทดลองในแบบจำลอง
- ค้นหาตามภารกิจ หน่วยงาน ผู้เกี่ยวข้อง หรือกรองตามหมวดได้
- เพิ่มสถานการณ์และแผนของทีมได้เอง ข้อมูลที่เพิ่มบันทึกใน Local Storage ของเบราว์เซอร์

## ขอบเขต
ข้อมูลบุคลากรและผลจำลองเป็นข้อมูลสมมติ ไม่มีการเชื่อมฐานข้อมูลราชการและไม่มีคำสั่งโอนย้ายคนจริง สถานการณ์ในเว็บเป็นกรณีออกแบบเพื่อการนำเสนอ ไม่ได้อ้างว่าเป็นเหตุการณ์จริง
